# Task bank sized 5–10 per level, not 5–10 per seminar

The written 10-July agreement says "5–10 задач на семинар". We deliberately encode the skill rule as **5–10 tasks per level** (база / среднее / сложное) — roughly 15–30 per seminar — because the intent behind "с запасом, чтобы разные преподы могли выбирать" is a reserve pool a teacher selects from, not the number a student solves. A reader comparing the skill to the meeting note would otherwise assume the literal per-seminar count and "correct" it back; this records that the larger bank is intentional.

# Question banks live in the public repo, answers included

The requirements asked for the generated questions to be kept in a private repository, which is the reflex any assessment invites. This repo is public, so honouring that would have meant a second repository on `git.ai.msu.ru` holding the banks, a deploy key, and a review workflow split across two places — the arrangement `msu/classroom` already uses for its course description. That option was on the table and was rejected.

Banks are stored in the open, next to the lectures they were written from, correct answers and all.

The reasoning is that secrecy was never doing the work anyway. A bank is written from one lecture's slides, and the slides are public; a student who wants the answers can read the source instead of the bank. Keeping the file hidden would buy secrecy only until the first screenshot circulates, and a leak would be silent — we would keep believing the quiz measures attention while it measures group-chat access. Publishing removes that failure mode by refusing to depend on it.

What holds the quiz up instead is stated plainly and can be reasoned about: a paper ticket handed out in the room, and two minutes. With fifty questions in the bank and five on screen, looking each one up costs more than answering it. If that stops being true, the fix is a shorter timer or a bigger bank — both visible knobs — rather than hoping a file stayed unnoticed.

There is a second benefit that matters more than the security argument. A bank is generated by a model and therefore contains mistakes: ambiguous options, two correct answers, questions about a slide that was cut. Public banks get read and fixed through pull requests, by the lecturer and eventually by students; private ones get read by nobody until they misfire in the lecture hall. The same reasoning already put tasks and solutions in the open in this repo.

Consequence to accept up front: this is irreversible. A bank that has been pushed is public forever, including for lectures reused next year, so a bank should be treated as course material — written to be readable — and never as an exam paper. Anything that must stay secret does not belong in this system at all.

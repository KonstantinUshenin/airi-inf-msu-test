# Auto-apply seminar format via a skill's trigger, not a settings.json hook

The seminar-formatting rules are packaged as a Claude skill (`.claude/skills/seminar-format/`) whose frontmatter `description` is written to trigger whenever seminar files (`seminars/**/{demo.ipynb,tasks.md,solutions.md}`) are being created or edited — deliberately WITHOUT a `.claude/settings.json` PostToolUse/PreToolUse hook. The original request said "apply automatically when seminar files are edited", so a future reader may expect a hard hook; we chose description-based triggering because it keeps the mechanism self-contained in the skill, needs no repo-wide settings change, and guides authoring (a post-edit hook could only react after the fact). Reversible later by adding a hook if stronger enforcement is wanted.

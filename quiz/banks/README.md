# Банки вопросов

По файлу на лекцию: `NN-тема.md`, слаг совпадает с именем `lectures/lecture-NN-тема.qmd`.

Пишутся скиллом `quiz-bank` по слайдам лекции, дальше **правятся руками через
pull request** — банк генерирует модель, и он ошибается ровно так, как ошибаются
модели: два верных варианта, вопрос про вырезанный слайд, формулировка, которая
выдаёт ответ.

Ответы лежат здесь открыто и это осознанно — `docs/adr/0005`. Прятать их
бессмысленно (вопросы написаны по открытым слайдам), а открытый банк хотя бы
вычитывают. Отсюда же следует, что **банк — это учебный материал, а не
экзаменационные билеты**: ничего, что должно остаться в тайне, здесь быть не может.

Формат разбирает свой парсер, и он строгий. Полные правила — в
`.claude/skills/quiz-bank/SKILL.md`, проверка:

```bash
python3 tools/lint_quiz_banks.py --stats
```

`ERROR` означает, что сервис такой банк не прочитает. Линтер обязателен в CI:
markdown ломается молча, и это единственное место, где поломка становится
громкой раньше, чем перед аудиторией.

**Идентификатор вопроса нельзя переиспользовать.** По нему собирается набор
студента и копится сводка «доля верных» за все прогоны. Поправить опечатку
можно, поменять смысл под тем же идентификатором — нельзя.

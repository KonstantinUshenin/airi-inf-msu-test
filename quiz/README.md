# Пятиминутки — короткие квизы после лекций

Студент сканирует QR с розданной бумажки, входит через университетский SSO,
отвечает на четыре вопроса с вариантами и один открытый, сразу видит разбор.
Преподаватель видит таблицу попыток, время на каждый вопрос и сводку по банку.

Термины — в корневом `CONTEXT.md`. Решения и их цена — в `docs/adr/0004`–`0007`.
Требования, из которых это выросло, — в спеке интервью
(`run/deep-interview/deep-interview-pyatiminutki.md`, не в git).

```
quiz/
  banks/            банки вопросов, по файлу на лекцию — их правят руками
  service/
    quizapp/        сервис
    tests/          69 тестов, без сети
tools/lint_quiz_banks.py   проверка банков, обязательна в CI
.claude/skills/quiz-bank/  правила написания банка
```

## Как это устроено

**Билет анонимен.** Печатается пачка одинаковых по смыслу бумажек, они
раздаются в аудитории кому попало. Билет доказывает, что человек был на лекции;
кто это — говорит SSO. Поэтому не нужен ни точный список группы за день до
лекции, ни раздача именных бумажек в правильные руки (`docs/adr/0004`).

**Персональных наборов не существует.** В git лежит только банк на лекцию
(≥40 вопросов с вариантами, ≥10 открытых). Набор 4+1 выбирается в момент входа
детерминированно от пары «лекция + логин»: у соседа другие вопросы, а
перезагрузка страницы и возврат после потери сети дают те же самые.

**Банк публичный, вместе с ответами** (`docs/adr/0005`). Секретность всё равно
не держится — вопросы написаны по слайдам, а слайды открыты. Держат
пятиминутку две вещи: бумажный билет и две минуты. Взамен банк читают и правят
через pull request, а он этого требует: его пишет модель, и он ошибается.

**Время живёт на сервере.** Дедлайн ставит сервер, ответ уходит в момент
нажатия, клиент только рисует отсчёт. Клиентские отметки времени не
принимаются: время на вопрос — главная метрика первых прогонов.

**Судья работает в фоне, всегда.** Сдача не делает ни одного исходящего
вызова. Открытый ответ кладётся в очередь; отсутствие вердикта — штатное
состояние. Провайдер лёг в момент, когда тридцать шесть человек жмут «Сдать», —
лекция этого не замечает.

## Первые два прогона

Идут в режиме `practice`: без таймера и без оценок. Цель — собрать тайминги и
обкатать процесс; решение о переходе в `graded` принимается по тому, как
прошло, а не по числовому порогу.

## Запуск

```bash
cd quiz/service
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/python -m pytest -q

export QUIZ_TEACHER_TOKEN=$(openssl rand -hex 16)
export QUIZ_BASE_URL=http://127.0.0.1:8391
.venv/bin/python -m quizapp serve
```

Перед лекцией — три команды:

```bash
python3 -m quizapp new 10-encoding            # завести (practice по умолчанию)
python3 -m quizapp tickets 1 --count 36 --pdf tickets.pdf   # выпустить и напечатать
python3 -m quizapp state 1 open               # открыть
```

После — `python3 -m quizapp state 1 closed`; результаты на `/teacher`.
То же самое есть по HTTP с заголовком `X-Quiz-Token` — см. страницу `/teacher`.

## Настройки

| Переменная | Зачем |
|---|---|
| `QUIZ_TEACHER_TOKEN` | преподавательский контур; без неё он выключен |
| `QUIZ_SECRET_KEY` | подпись сессионных кук; без неё сессии живут до перезапуска |
| `QUIZ_BASE_URL` | что зашивается в QR и redirect_uri |
| `QUIZ_STATE_DIR` | где лежит `quiz.sqlite` (по умолчанию `~/.local/state/quiz`) |
| `QUIZ_BANKS_DIR` | где искать банки (по умолчанию `quiz/banks`) |
| `QUIZ_AUTH_MODE` | `test` (ФИО руками) или `oidc` (authentik) |
| `QUIZ_OIDC_ISSUER` | `https://auth.ai.msu.ru/application/o/<слаг>` |
| `QUIZ_OIDC_CLIENT_ID`, `QUIZ_OIDC_CLIENT_SECRET` | приложение в authentik |
| `REVIEW_API_KEY` / `DEEPSEEK_API_KEY`, `REVIEW_MODEL` | судья; конвенция репозитория |
| `QUIZ_JUDGE_ENABLED` | выключить судью целиком |

Тестовый режим авторизации существует, чтобы разработка и первая лекция не
ждали регистрации приложения в authentik. Попытки из него помечены `тест`
и видны такими же преподавателю.

## Деплой

Ansible-роль `quiz` живёт в отдельном репозитории — `msu/infra`
(gitverse `fai-msu-ics/infra`), рядом с ролями `classroom` и `jupyterhub`.
Сервис слушает `127.0.0.1`, наружу выходит через nginx с TLS.

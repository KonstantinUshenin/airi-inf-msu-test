Как завести и открыть

Управление — по API, тем же токеном. Он же в заголовке X-Quiz-Token.

TOKEN=…
BASE={{ settings.base_url }}

# создать (mode: practice — без оценок и таймера; graded — боевой режим)
curl -sX POST $BASE/api/teacher/quizzes -H "X-Quiz-Token: $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"lecture":"10-encoding","mode":"practice"}'

# выпустить билеты и забрать лист на печать
curl -sX POST $BASE/api/teacher/quizzes/1/tickets -H "X-Quiz-Token: $TOKEN" \
  -H 'Content-Type: application/json' -d '{"count":36}'
curl -s $BASE/api/teacher/quizzes/1/tickets.pdf -H "X-Quiz-Token: $TOKEN" -o tickets.pdf

# открыть перед раздачей и закрыть после
curl -sX POST $BASE/api/teacher/quizzes/1/state -H "X-Quiz-Token: $TOKEN" \
  -H 'Content-Type: application/json' -d '{"state":"open"}'

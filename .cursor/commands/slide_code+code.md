# Добавить двухколоночный слайд Quarto (код + код)

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции в формате двух колонок проекта: **слева пример на одном языке, справа — на другом**. Одна и та же идея / задача в двух языках для сравнения.

Весь диалог с пользователем и заголовок слайда — **на русском**, если пользователь явно не попросил другой язык. Имена языков в подзаголовках колонок (`### Python`, `### C`, …) и код не переводи без нужды. Комментарии в коде — на русском, если пользователь не указал иное.

## Входные данные

Используй аргументы после `/slide_code+code` и любые `@`-ссылки на файл. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##`, на русском
- **Язык слева и язык справа** — два разных языка (например C и Python, Python и Java, Rust и C++)
- **Два фрагмента кода** — параллельные примеры одной идеи; если кода нет — предложи короткие сопоставимые фрагменты по теме

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`
- Краткие пояснения `*` под кодом в колонке — допустимы, если нужны для сравнения (как в слайде Python/Java про конкатенацию строк)
- Несколько коротких code fence в одной колонке — допустимы (плохой vs хороший вариант и т.п.)

## Шаблон (строго как в существующих лекциях)

````markdown
---

## ЗАГОЛОВОК ЗДЕСЬ

::: columns
::: column

### Python

```python
# короткий параллельный пример
s = "".join(parts)
```

:::

::: column

### Java

```java
// тот же смысл на другом языке
StringBuilder sb = new StringBuilder();
for (String x : parts) {
    sb.append(x);
}
String s = sb.toString();
```

:::
:::
````

Замечания по структуре:
- `##` начинает новый слайд
- `::: columns` оборачивает обе колонки; каждая `::: column` — одна колонка; закрывай `:::` на колонку, затем `:::` на columns
- В каждой колонке: подзаголовок `### Язык` и fenced code block с правильным языком подсветки
- **Два разных языка** — не дублировать один и тот же язык слева и справа
- Фрагменты должны быть сопоставимы по смыслу и примерно одинаковой длины
- Код короткий: помещаться на слайд, без лишнего boilerplate (лучше 5–15 строк на колонку)
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори отступы и стиль соседних слайдов; заголовок пиши по-русски, если пользователь не указал иное.
2. Собери слайд по шаблону: два языка, два параллельных фрагмента — из ввода пользователя (или предложи сам).
3. Выровняй примеры по смыслу: одна задача, два идиоматичных решения.
4. Вставь слайд в выбранное место, не переписывая чужой контент.
5. Ответь по-русски: какой заголовок вставлен, какие два языка и куда поставлен слайд (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать HTML `<div>` вместо Quarto `::: columns`
- Ставить текст/картинку вместо кода в одной из колонок (для этого есть `/slide_text`, `/slide_text+code`, `/slide_text+img`)
- Ставить один и тот же язык в обеих колонках
- Добавлять speaker notes, callouts и лишний декор без запроса
- Пихать на слайд длинные программы
- Отвечать пользователю по-английски (если он сам не переключился на английский)

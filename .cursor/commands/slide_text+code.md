# Добавить двухколоночный слайд Quarto (текст + код)

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции в формате двух колонок проекта: **слева текст, справа пример кода**.

Весь диалог с пользователем и содержимое слайда (заголовок, пункты списка, комментарии в коде при необходимости) — **на русском**, если пользователь явно не попросил другой язык. Синтаксис Quarto (`::: columns`, fenced code blocks, YAML) и идентификаторы в коде не переводи без нужды.

## Входные данные

Используй аргументы после `/slide_text+code` и любые `@`-ссылки на файл. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##`, на русском
- **Содержимое левой колонки** — вложенный маркированный список и/или короткие пояснения, на русском
- **Пример кода** — язык (python / bash / c / sql / …) и сам фрагмент; если кода нет — предложи короткий иллюстративный пример по теме

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`
- **Заголовок правой колонки** — например `### Примеры` (как в слайдах про `sed`/`awk`); по умолчанию можно без подзаголовка, если один блок кода
- Несколько коротких code fence подряд допустимы, если так нагляднее

## Шаблон (строго как в существующих лекциях)

````markdown
---

## ЗАГОЛОВОК ЗДЕСЬ

::: columns
::: column

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт

:::

::: column

### Примеры

```python
# короткий иллюстративный фрагмент
print("hello")
```

:::
:::
````

Замечания по структуре:
- `##` начинает новый слайд
- `::: columns` оборачивает обе колонки; каждая `::: column` — одна колонка; закрывай `:::` на колонку, затем `:::` на columns
- Левая колонка: вложенные списки `-` и короткий текст (как в `lecture-10-encoding.qmd`)
- Правая колонка: один или несколько fenced code block с языком (`python` / `bash` / `c` / `sql` и т.д.)
- Код должен быть коротким: помещаться на слайд, без лишнего boilerplate
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори отступы и стиль соседних слайдов; текст пиши по-русски (даже если рядом слайды на английском), если пользователь не указал иное.
2. Собери слайд по шаблону: заголовок, пункты слева, код справа — из ввода пользователя.
3. Выбери язык подсветки по контексту лекции и теме слайда.
4. Вставь слайд в выбранное место, не переписывая чужой контент.
5. Ответь по-русски: какой заголовок вставлен, язык кода и куда поставлен слайд (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать HTML `<div>` вместо Quarto `::: columns`
- Ставить код слева, а текст справа (если пользователь явно не попросил иначе)
- Вставлять картинку вместо кода (для этого есть `/slide_text+img`)
- Добавлять speaker notes, callouts и лишний декор без запроса
- Пихать на слайд длинные программы — лучше 5–15 строк
- Отвечать пользователю по-английски (если он сам не переключился на английский)

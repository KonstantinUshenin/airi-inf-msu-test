# Добавить текстовый слайд Quarto (одна колонка)

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции: **один основной блок текста с пунктами на весь слайд**. Без двух колонок, без картинки и без блока кода как второй колонки.

Весь диалог с пользователем и содержимое слайда (заголовок, пункты списка) — **на русском**, если пользователь явно не попросил другой язык. Синтаксис Quarto и YAML не переводи.

## Входные данные

Используй аргументы после `/slide_text` и любые `@`-ссылки на файл. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##`, на русском
- **Содержимое** — вложенный маркированный список (разделы и пункты), на русском

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`
- Короткие акценты через `**жирный**` в пунктах — допустимы, если так в соседних слайдах

## Шаблон (строго одна колонка)

```markdown
---

## ЗАГОЛОВОК ЗДЕСЬ

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт
```

Замечания по структуре:
- `##` начинает новый слайд
- **Не** использовать `::: columns` / `::: column`
- Только вложенные списки `-` на всю ширину слайда (как в `lecture-10-encoding.qmd`, слайд «What types of encodings exist?»)
- Без картинки, без fenced code как основной второй колонки; инлайн-``код`` в пунктах допустим
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори отступы и стиль списков соседних слайдов; текст пиши по-русски, если пользователь не указал иное.
2. Собери слайд по шаблону: заголовок и пункты — из ввода пользователя.
3. Вставь слайд в выбранное место, не переписывая чужой контент.
4. Ответь по-русски: какой заголовок вставлен и куда (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать `::: columns`, HTML `<div>` или любую двухколоночную вёрстку
- Добавлять картинку или боковой блок кода (для этого есть `/slide_text+img` и `/slide_text+code`)
- Добавлять speaker notes, callouts и лишний декор без запроса
- Отвечать пользователю по-английски (если он сам не переключился на английский)

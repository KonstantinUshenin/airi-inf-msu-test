# Добавить слайд Quarto с одним центрированным изображением

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции: **одно центрированное изображение на весь слайд**. Без двух колонок, без списков и без блока кода.

Весь диалог с пользователем и заголовок слайда — **на русском**, если пользователь явно не попросил другой язык. Синтаксис Quarto, пути к файлам и YAML не переводи.

## Входные данные

Используй аргументы после `/slide_image` и любые `@`-ссылки на файл/картинку. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##`, на русском
- **Путь к картинке** — относительно `.qmd` (например `images/Foo.png`); если файла ещё нет — оставь placeholder-путь

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`
- **Ширина** — например `width="80%"` / `width="70%"`; по умолчанию `width="80%"`
- Подпись к рисунку — только если пользователь явно просит

## Шаблон

```markdown
---

## ЗАГОЛОВОК ЗДЕСЬ {.center}

![](images/PLACEHOLDER.png){fig-align="center" width="80%"}
```

Замечания по структуре:
- `##` начинает новый слайд
- `{.center}` на заголовке вертикально центрирует содержимое слайда (Reveal.js)
- `{fig-align="center"}` горизонтально центрирует изображение
- **Не** использовать `::: columns` / `::: column`
- На слайде только заголовок и одно изображение (как идея слайда ASCII в `lecture-10-encoding.qmd`, но с явным центрированием)
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори стиль соседних слайдов; заголовок пиши по-русски, если пользователь не указал иное.
2. Собери слайд по шаблону: заголовок и путь к картинке — из ввода пользователя.
3. Вставь слайд в выбранное место, не переписывая чужой контент.
4. Если файла картинки нет — всё равно укажи данный (или разумный `images/...`) путь и скажи, что ассет нужно добавить.
5. Ответь по-русски: какой заголовок вставлен, какой путь к картинке и куда поставлен слайд (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать `::: columns`, HTML `<div>` или двухколоночную вёрстку
- Добавлять списки, код или второе изображение без запроса (для текста/кода есть `/slide_text`, `/slide_text+code`, `/slide_code+code`; для текста+картинки — `/slide_text+img`)
- Добавлять speaker notes, callouts и лишний декор без запроса
- Отвечать пользователю по-английски (если он сам не переключился на английский)

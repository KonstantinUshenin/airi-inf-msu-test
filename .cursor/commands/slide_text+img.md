# Добавить двухколоночный слайд Quarto

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции в формате двух колонок проекта: **слева текст, справа картинка**.

Весь диалог с пользователем и содержимое слайда (заголовок, пункты списка) — **на русском**, если пользователь явно не попросил другой язык. Синтаксис Quarto (`::: columns`, пути к файлам, YAML) не переводи.

## Входные данные

Используй аргументы после `/add-two-column` и любые `@`-ссылки на файл/картинку. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##` (тема + опционально год/эпоха), на русском
- **Содержимое левой колонки** — вложенный маркированный список (Идея / Тип / Правила / …), на русском
- **Путь к картинке** — относительно `.qmd` (например `images/Foo.png`); если файла ещё нет — оставь placeholder-путь

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`

## Шаблон (строго как в существующих лекциях)

```markdown
---

## ЗАГОЛОВОК ЗДЕСЬ

::: columns
::: column

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт

:::

::: column

![](images/PLACEHOLDER.png)

:::
:::
```

Замечания по структуре:
- `##` начинает новый слайд
- `::: columns` оборачивает обе колонки; каждая `::: column` — одна колонка; зсакрывай `:::` на колонку, затем `:::` на columns
- Левая колонка: только вложенные списки `-` (как в `lecture-10-encoding.qmd`)
- Правая колонка: одно markdown-изображение `![](...)` — без подписи, если пользователь не просил
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори отступы и стиль списков соседних слайдов; текст пиши по-русски (даже если рядом слайды на английском), если пользователь не указал иное.
2. Собери слайд по шаблону: заголовок, пункты и путь к картинке — из ввода пользователя (на русском).
3. Вставь слайд в выбранное место, не переписывая чужой контент.
4. Если файла картинки нет — всё равно укажи данный (или разумный `images/...`) путь и скажи, что ассет нужно добавить.
5. Ответь по-русски: какой заголовок вставлен и куда (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать HTML `<div>` вместо Quarto `::: columns`
- Ставить картинку слева, а текст справа
- Добавлять speaker notes, callouts и лишний декор без запроса
- Отвечать пользователю по-английски (если он сам не переключился на английский)

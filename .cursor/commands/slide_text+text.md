# Добавить двухколоночный слайд Quarto (текст + текст)

Вставь новый слайд в активный (или указанный) `.qmd`-файл лекции в формате двух колонок проекта: **слева текст, справа текст**. Без картинки и без блока кода.

Весь диалог с пользователем и содержимое слайда (заголовок, пункты списка) — **на русском**, если пользователь явно не попросил другой язык. Синтаксис Quarto (`::: columns`, YAML) не переводи.

## Входные данные

Используй аргументы после `/slide_text+text` и любые `@`-ссылки на файл. Если чего-то не хватает — коротко спроси на русском перед правкой.

Нужно / желательно:
- **Целевой `.qmd`** — файл в фокусе редактора, `@path` или явный путь в `lectures/`
- **Заголовок слайда** — короткий `##`, на русском
- **Левая колонка** — вложенный маркированный список и/или короткие пояснения, на русском
- **Правая колонка** — вложенный маркированный список и/или короткие пояснения, на русском

Опционально:
- **Место вставки** — после указанного заголовка, у курсора или перед секцией `#` / `##`; по умолчанию: после слайда с курсором или в конце ближайшей секции `#`
- **Подзаголовки колонок** — например `### OSI` / `### TCP/IP`; допустимы, если так нагляднее сравнивать
- Короткие акценты через `**жирный**` и инлайн-``код`` в пунктах — допустимы

## Шаблон

```markdown
---

## ЗАГОЛОВОК ЗДЕСЬ

::: columns
::: column

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт

:::

::: column

- Раздел
  - Пункт
  - Пункт

- Раздел
  - Пункт

:::
:::
```

Замечания по структуре:
- `##` начинает новый слайд
- `::: columns` оборачивает обе колонки; каждая `::: column` — одна колонка; закрывай `:::` на колонку, затем `:::` на columns
- Обе колонки: вложенные списки `-` (как в `lecture-10-encoding.qmd`)
- Объём колонок примерно сопоставим — слайд не должен «перекашиваться» в одну сторону
- Без картинки и без fenced code (для этого есть `/slide_text+img`, `/slide_text+code`, `/slide_code+code`)
- Ставь `---` **перед** новым слайдом, если он идёт после другого (пустые строки — как у соседних слайдов)

## Шаги

1. Открой/прочитай целевой `.qmd` и повтори отступы и стиль списков соседних слайдов; текст пиши по-русски, если пользователь не указал иное.
2. Собери слайд по шаблону: заголовок и содержимое обеих колонок — из ввода пользователя.
3. Вставь слайд в выбранное место, не переписывая чужой контент.
4. Ответь по-русски: какой заголовок вставлен и куда (после какого заголовка / примерно какая строка).

## Нельзя

- Менять YAML frontmatter или другие слайды без просьбы
- Использовать HTML `<div>` вместо Quarto `::: columns`
- Ставить картинку или код вместо текста в одной из колонок
- Делать одну колонку — для этого есть `/slide_text`
- Добавлять speaker notes, callouts и лишний декор без запроса
- Отвечать пользователю по-английски (если он сам не переключился на английский)

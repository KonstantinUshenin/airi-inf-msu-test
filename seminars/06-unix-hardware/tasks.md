# Практическая работа

**Выход:** `.sh`, `.py` или `.ipynb`.

Все задачи выполняются **на своей виртуальной машине, в домашнем каталоге**
(например, в `~/seminar-06/`). Каталог `/tmp` не используем: он вычищается при
перезагрузке, а отчёты нужны вам до защиты. Скопируйте туда данные семинара и
работайте из этого каталога:

```bash
mkdir -p ~/seminar-06
cp -r ПУТЬ-К-РЕПОЗИТОРИЮ/seminars/06-unix-hardware/assets ~/seminar-06/
cd ~/seminar-06
```

Часть задач читает железо текущей машины — их результат у всех разный, поэтому
в примерах указан **формат** вывода, а не конкретные числа. Задачи на разбор
работают с сохранёнными файлами из `assets/`: `cpuinfo.txt`, `meminfo.txt`,
`lsblk.json` и `nvidia-smi.csv` — у них ответ один и тот же на любой машине.
Пути в примерах относительные и предполагают, что вы находитесь в `~/seminar-06`.

## База — 6 задач

### B1. Процессор

**need:** Linux; `lscpu`.

Соберите в `cpu.txt` архитектуру, модель процессора, число логических процессоров и число ядер на сокет.

**Пример:** `nproc` печатает одно число (`12` на машине преподавателя); в `cpu.txt` есть строка вида `Model name: AMD Ryzen 5 5600U with Radeon Graphics`.

### B2. Память

**need:** Linux.

Сохраните в `memory.txt` вывод `free -h` и три строки из `/proc/meminfo`: `MemTotal`, `MemAvailable`, `SwapTotal`.

**Пример:** в файле есть строка вида `MemTotal:       14156792 kB`; значение зависит от машины.

### B3. Диски

**need:** Linux; `lsblk`.

Сохраните в `disks.txt` дерево блочных устройств без loop-устройств и занятость файловой системы, на которой лежит текущий каталог.

**Пример:** `lsblk -e 7 -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS` печатает дерево вида `nvme0n1 → nvme0n1p1, nvme0n1p2`; `df -h .` даёт строку вида `/dev/nvme0n1p2  938G  861G   29G  97% /`.

### B4. Устройства на шинах

**need:** Linux; `lspci`, `lsusb`.

Сохраните в `devices.txt` число устройств на шине PCI, строку про видеоконтроллер и число устройств USB.

**Пример:** строка про видео выглядит как `04:00.0 VGA compatible controller: Advanced Micro Devices, Inc. [AMD/ATI] Cezanne (rev c2)`; числа зависят от машины.

### B5. Процессоры в сохранённом `/proc/cpuinfo`

**need:** `assets/cpuinfo.txt`.

Посчитайте число логических процессоров в сохранённом файле и выведите модель процессора. Результат сохраните в `saved-cpu.txt`.

**Пример:** `4` процессора, модель `Intel(R) Xeon(R) Gold 6248R CPU @ 3.00GHz`.

### B6. Проверка наличия GPU

**need:** Linux.

Напишите `gpu-check.sh`: если `nvidia-smi` доступна — сохранить её вывод в `gpu-check.txt`, иначе записать туда `gpu=none`. Скрипт должен завершаться кодом `0` в обоих случаях.

**Пример:** на машине без видеокарты NVIDIA → `gpu-check.txt` содержит `gpu=none`, код возврата `0`.

## Среднее — 7 задач

### M1. Ядра и потоки

**need:** `assets/cpuinfo.txt`.

Посчитайте число логических процессоров и число физических ядер. Сохраните в `cores.txt` двумя строками `logical=…` и `physical=…`. Физическое ядро определяется парой `physical id` + `core id`.

**Пример:** `logical=4`, `physical=2`.

### M2. Память в гигабайтах

**need:** `assets/meminfo.txt`; Python 3.

Напишите `meminfo.py`, который печатает `MemTotal`, `MemAvailable` и `SwapTotal` в GiB с одним знаком после запятой. Значения в файле указаны в килобайтах.

**Пример:** `MemTotal=125.8 GiB`, `MemAvailable=93.7 GiB`, `SwapTotal=8.0 GiB`.

### M3. Свободная GPU

**need:** `assets/nvidia-smi.csv`; Python 3.

Найдите видеокарту с наибольшим объёмом свободной памяти и напечатайте её индекс и свободную память.

**Пример:** `gpu=3 free=40448 MiB`.

### M4. Данные о машине через `subprocess`

**need:** Linux; Python 3.

Напишите `hwinfo.py`, который получает число процессоров вызовом `nproc` через `subprocess` и объём памяти из `/proc/meminfo`. Ошибка внешней команды не должна проходить незамеченной.

**Пример:** на машине с 12 логическими процессорами → `cpus=12` и строка вида `mem_total_gib=13.5`.

### M5. Блочные и символьные устройства

**need:** Linux.

Разберитесь, какие устройства в `/dev` блочные, а какие символьные, и что стоит у них вместо размера. Сохраните в `devices.txt` по одной строке на `/dev/null`, `/dev/random` и первый диск из `lsblk`, указав для каждого тип (`b` или `c`) и пару major:minor.

**Пример:** у `/dev/null` тип `c` и пара `1, 3`, у диска — тип `b`; вместо размера у обоих стоят два числа, потому что это точки входа в драйвер, а не файлы с данными.

### M6. Диски из JSON

**need:** `assets/lsblk.json`; Python 3.

Напечатайте имя и размер каждого диска (`type == "disk"`) в GiB и суммарный объём всех дисков в TiB.

**Пример:** `nvme0n1 931.5 GiB`, `sda 3726.0 GiB`, `sdb 476.9 GiB`, `total 5.01 TiB`.

### M7. Здоровье диска

**need:** Linux; `smartmontools` (`sudo apt install smartmontools`); права root.

Снимите вердикт SMART для системного диска и сохраните в `smart.txt` короткий отчёт: модель, число часов работы и число переназначенных секторов. Если `smartctl` не установлен или прав не хватает, скрипт должен сказать об этом человеческим языком и завершиться кодом `0`.

**Пример:** `sudo smartctl -H /dev/nvme0n1` печатает строку с вердиктом `PASSED`; на машине без `smartmontools` в `smart.txt` попадает `smartctl не установлен`.

## Сложное — 6 задач

### H1. Отчёт о машине

**need:** Linux; Python 3.

Напишите `hw-report.py РАЗДЕЛ [json]`, где раздел — один из `cpu`, `mem`, `disk`, `gpu`, `all`. Второй аргумент переключает вывод в JSON. Отсутствие утилиты не должно ронять отчёт: соответствующий раздел получает пустое значение, остальные собираются. Аргументы разберите через `sys.argv`.

**Пример:** `python3 hw-report.py cpu json` печатает объект с разделом `cpu`, внутри которого ключи `logical_cpus` и `model`; код `0`. На машине без NVIDIA раздел `gpu` равен `null`, код по-прежнему `0`.

### H2. Подбор параметров обучения

**need:** `assets/nvidia-smi.csv`, `assets/cpuinfo.txt`; Python 3.

Напишите `suggest.py GPU_CSV CPUINFO ПАМЯТЬ_НА_ОБРАЗЕЦ` (все три аргумента позиционные). Скрипт выбирает самую свободную видеокарту и печатает её индекс, размер батча и число загрузчиков данных. Батч считается как `int(free_mib * 0.9 / per_sample_mib)` — десять процентов памяти остаются в запасе; загрузчиков берут по числу физических ядер.

**Пример:** `python3 suggest.py assets/nvidia-smi.csv assets/cpuinfo.txt 512` → `gpu=3 batch=71 num_workers=2`.

### H3. Запуск команды с ограничением по времени

**need:** Python 3.

Напишите `run-timeout.py СЕК КОМАНДА…`, который запускает команду через `subprocess` и печатает её код возврата и длительность. Если команда не уложилась в срок — сообщить об этом и завершиться кодом `124`. Аргументы разберите через `sys.argv`.

**Пример:** `python3 run-timeout.py 1 sleep 5` → `timeout after 1 s` и код `124`; `python3 run-timeout.py 5 true` → `returncode=0` и код `0`.

### H4. Несколько дочерних процессов через `fork`

**need:** Linux; Python 3.

Напишите `fork-workers.py N [K]`, который порождает `N` процессов через `os.fork()`. Каждый ребёнок печатает свой pid и pid родителя; необязательный второй аргумент `K` — номер ребёнка, который завершится ненулевым кодом. Родитель дожидается всех и завершается кодом `1`, если упал хотя бы один.

**Пример:** `python3 fork-workers.py 3` → три строки `child …` и `parent: children=3 failed=0`, код `0`. `python3 fork-workers.py 3 1` → `failed=1` и код `1`.

### H5. Заполненные файловые системы

**need:** Linux.

Напишите `disk-alert.sh ПОРОГ`, который печатает файловые системы, занятые больше порога в процентах, и завершается кодом `1`, если такая нашлась. Псевдофайловые системы (`tmpfs`, `devtmpfs`) и образы пакетов snap (`squashfs`, всегда заполнены на 100 %) учитывать не нужно.

**Пример:** `./disk-alert.sh 100` → пустой вывод и код `0`; `./disk-alert.sh 1` → список смонтированных файловых систем и код `1`.

### H6. Проверка окружения

**need:** Linux.

Напишите `check-tools.sh`, который проверяет наличие `lscpu`, `lsblk`, `df`, `lspci` и `nvidia-smi` и печатает по строке на утилиту. Первые четыре обязательны: если хоть одной нет — код `1`. Отсутствие `nvidia-smi` на код возврата не влияет.

**Пример:** на машине без видеокарты NVIDIA → строка `nvidia-smi missing`, остальные `found`, код возврата `0`.

# Домашняя работа

**Выход:** `.py` или `.ipynb`.

Работаем в `~/seminar-11/`, а не в `/tmp`. Входные данные готовит тот же скрипт, что и для практической работы:

```bash
cd ~/seminar-11
./generate.sh
```

Данные домашней работы лежат в `assets/HOME1/`, `assets/HOME2/` и `assets/HOME3/`. Для второй задачи нужен учебный сервер:

```bash
uv run uvicorn api_server:app --app-dir assets --port 8000
```

## 1. Каталог данных

**need:** `assets/HOME1/catalog.json`.

Пример входного JSON (в файле записей больше, часть из них ошибочна):

```json
[
  {"id": 1, "name": "Keyboard", "price": 4900},
  {"id": 2, "name": "", "price": 2100},
  {"id": 3, "name": "Monitor", "price": "23000"}
]
```

Корректная запись содержит целый `id`, непустую строку `name` и числовой `price`. Проверьте записи, ошибочные с индексом и причиной сохраните в `catalog-errors.json`. Корректные преобразуйте в `catalog.xml`, прочитайте его обратно и сохраните в `restored.json`. После обратного преобразования значения и числовые типы должны совпасть с исходными.

**Пример** `catalog-errors.json` для входа выше: `[{"index": 1, "reason": "invalid name"}, {"index": 2, "reason": "invalid price"}]`.

## 2. API с постраничной выдачей

**need:** запущенный `assets/api_server.py`; `requests`; адрес `http://127.0.0.1:8000/items`; начальный кэш `assets/HOME2/cache.json`.

Адрес `/items` отдаёт страницы по два элемента и в поле `next` сообщает номер следующей страницы либо `null`, если страниц больше нет:

```json
{"items": [{"id": 1, "title": "JSON"}, {"id": 2, "title": "XML"}], "next": 2}
```

Заберите все страницы, пока `next` не станет `null`, удалите дубли по `id` и сохраните полный список в `items.json`. Сводку (`total`, список `titles`) сохраните в `items-summary.json`. Затем обновите кэш: скопируйте `assets/HOME2/cache.json` к себе и перезапишите его новым списком **безопасно** — сначала во временный файл, затем `os.replace`, чтобы прерванный на середине запуск не испортил старый кэш.

**Пример** `items-summary.json`: `{"total": 5, "titles": ["JSON", "XML", "HTTP", "HTML", "OpenAI API"]}`.

## 3. HTML-каталог из нескольких страниц

**need:** `assets/HOME3/pages/`; Beautiful Soup.

Ссылки на соседние страницы имеют класс `.page`, товары — класс `.product`. Часть карточек ошибочна: без ссылки или с пустым названием. Одна из ссылок ведёт на несуществующий файл — обход не должен на ней падать. Начиная с `assets/HOME3/pages/page1.html`, обойдите все доступные страницы, не читая ни одну дважды.

Товары с абсолютными адресами (`urljoin` от `file://`-адреса страницы) и без дублей по URL сохраните в `products.json`, ошибочные карточки — в `errors.json` с номером страницы и причиной.

**Пример** `errors.json`: `[{"page": "page1.html", "reason": "карточка без ссылки"}, {"page": "page2.html", "reason": "карточка без названия"}]`.

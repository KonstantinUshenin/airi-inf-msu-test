# Домашняя работа

**Выход:** `.py` или `.ipynb`.

## 1. Каталог данных

**need:** `catalog.json` с корректными и ошибочными записями.

Проверьте записи, сохраните ошибки отдельно. Корректные данные преобразуйте в `catalog.xml`, прочитайте обратно и сохраните в `restored.json`.

## 2. API

**need:** постраничный JSON API и начальный рабочий кэш.

Получите все страницы, удалите дубли и безопасно обновите кэш. Сохраните исходные записи и сводку по ним в разные JSON-файлы.

## 3. HTML-каталог

**need:** несколько связанных локальных страниц с корректными и ошибочными карточками.

Обойдите страницы без повторов. Сохраните товары с абсолютными ссылками в `products.json`, ошибки карточек — в `errors.json`.

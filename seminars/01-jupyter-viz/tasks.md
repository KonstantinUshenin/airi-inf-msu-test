# Практическая работа

**Выход:** `.ipynb`. Задачи решаются в Jupyter Notebook или Google Colab.

Задачи разбиты на три уровня. Базовые задачи — обязательный минимум, по ним
отмечают, кто их решил. Список задач с запасом — преподаватель выбирает, что
давать.

## База

### B1. Ядро и порядок выполнения

**need:** Jupyter/IPython.

Заведите в ноутбуке две ячейки: первая создаёт переменную, вторая её печатает.
Выполните их **в обратном порядке** и покажите полученную ошибку. Затем
перезапустите ядро, выполните всё сверху вниз (Run All) и покажите, что вывод
стал правильным. Объясните в комментарии, почему результат ноутбука зависит не от
того, что в ячейках написано, а от того, в каком порядке их запускали.

**Пример:** запуск второй ячейки первой печатает
`NameError: name 'answer' is not defined`; после Restart Kernel и Run All —
`42`.

### B2. Магии ноутбука

**need:** Jupyter/IPython.

Покажите работу магий и shell в ноутбуке: узнайте текущий каталог (`%pwd`),
список определённых переменных (`%who`), версию Python через shell (`!`) и
замерьте время выражения (`%timeit`).

**Пример:** после `x = 5` магия `%who` выводит строку с `x`; `%timeit sum(range(10**6))`
печатает усреднённое время одного запуска.

### B3. Создание массивов NumPy

**need:** `numpy`.

Создайте массив из списка `[1, 4, 9, 16, 25]` и массив из 5 равномерных точек на
отрезке `[0, 1]` через `np.linspace`. Для каждого выведите `shape` и `dtype`
(это атрибуты, без скобок).

**Пример:** `np.linspace(0, 1, 5)` → `[0.   0.25 0.5  0.75 1.  ]`, его `shape` → `(5,)`.

### B4. Поэлементные операции и broadcasting

**need:** `numpy`.

Для массива `a = np.arange(5)` вычислите квадрат каждого элемента, корень
(`np.sqrt`) и прибавьте скаляр `10` (broadcasting). Сложите два массива одинаковой
длины поэлементно.

**Пример:** `a ** 2` → `[ 0  1  4  9 16]`, `a + 10` → `[10 11 12 13 14]`.

### B5. Индексирование и срезы

**need:** `numpy`.

Для массива `x = np.arange(10)` получите: подмассив с 3-го по 5-й элемент, три
последних элемента и все чётные элементы через булеву маску.

**Пример:** `x[2:5]` → `[2 3 4]`, `x[-3:]` → `[7 8 9]`, `x[x % 2 == 0]` → `[0 2 4 6 8]`.

### B6. Первый график

**need:** `numpy`, `matplotlib`.

Постройте график `y = sin(x)` на отрезке `[0, 2π]` (не меньше 100 точек).
Подпишите оси и заголовок, включите сетку и сохраните график в `sin.png`
(сохранение — **до** `show`).

**Пример:** после решения файл `sin.png` существует и не пустой; линия гладкая.

## Среднее

### M1. Векторизация против цикла

**need:** `numpy`.

Вычислите сумму квадратов чисел `0..N-1` двумя способами: циклом Python и
векторизованным NumPy. Убедитесь, что результат совпадает, и сравните время через
`%timeit`.

**Пример:** для `N = 10**6` оба способа дают `333332833333500000`; версия NumPy
заметно быстрее по `%timeit`.

### M2. Broadcasting в 2D

**need:** `numpy`.

Постройте матрицу 3×4, где `a[i, j] = i + j`, **без циклов** — сложением
вектора-столбца и вектора-строки.

**Пример:** результат равен `[[0 1 2 3], [1 2 3 4], [2 3 4 5]]`.

### M3. Агрегации по осям

**need:** `numpy`.

Для матрицы `M = np.arange(6).reshape(2, 3)` посчитайте сумму по столбцам
(`axis=0`) и по строкам (`axis=1`), а также индекс максимума во всей матрице.

**Пример:** `M.sum(axis=0)` → `[3 5 7]`, `M.sum(axis=1)` → `[ 3 12]`,
`M.argmax()` → `5`.

### M4. Несколько графиков (subplots)

**need:** `numpy`, `matplotlib`.

Постройте фигуру 2×2 с графиками `y = x²`, `y = x³ − 3x`, `y = sin(x)/x`
(используйте `np.sinc(x/np.pi)`, чтобы избежать деления на ноль) и `y = ln(1 + x²)`
на `[-5, 5]`. У каждого — заголовок с формулой и сетка; вызовите `tight_layout` и
сохраните фигуру.

**Пример:** у фигуры ровно 4 области (`axes.shape == (2, 2)`), файл сохранён.

### M5. Гистограмма и плотность

**need:** `numpy`, `matplotlib`.

Сгенерируйте 10 000 чисел из стандартного нормального распределения и постройте
гистограмму с `bins=50` и `density=True`. Наложите теоретическую плотность
`(1/√(2π))·exp(−x²/2)`.

**Пример:** при `density=True` площадь гистограммы ≈ 1, и теоретическая кривая
совпадает по масштабу с гистограммой (пик ≈ 0.4).

### M6. Тот же ноутбук в Colab

**need:** аккаунт Google; ноутбук из предыдущих задач.

Загрузите свой ноутбук в Google Colab и добейтесь, чтобы он выполнялся там
сверху вниз без правок кода. Проверьте, какая версия Python и какие версии
`numpy`/`matplotlib` стоят в Colab, и установите недостающий пакет прямо из
ноутбука. Сохраните результат работы (картинку или файл) так, чтобы он не
пропал после отключения сессии, и объясните в комментарии, почему файл в рабочем
каталоге Colab пропадает, а на Google Drive — нет.

**Пример:** `!python --version` в Colab печатает версию Python рантайма,
`!pip install plotly` доустанавливает пакет, а `plt.savefig` с путём внутри
подключённого `/content/drive/MyDrive/...` оставляет картинку после закрытия
сессии.

## Сложное

### H1. Функция двух переменных

**need:** `numpy`, `matplotlib`.

На квадрате `[-3, 3] × [-3, 3]` (шаг 0.05, `np.meshgrid`) вычислите
`z = sin(x² + y²)`. Постройте два изображения: `imshow` (с `origin='lower'`) и
`contourf`, к каждому добавьте `colorbar`.

**Пример:** сетка квадратная (`Z.shape` вида `(121, 121)` для шага 0.05 с обеими
границами); карта `imshow` не
перевёрнута по вертикали, у обоих графиков есть шкала значений.

### H2. Оценка π методом Монте-Карло

**need:** `numpy`, `matplotlib`.

Векторно сгенерируйте `N` случайных точек в квадрате `[0,1]²` и оцените π как
долю точек внутри четверти круга, умноженную на 4. Постройте график сходимости
оценки к π с ростом числа точек.

**Пример:** при `np.random.default_rng(0)` и `N = 10**6` оценка отличается от `np.pi`
меньше чем на `0.01`.

### H3. Множество Мандельброта

**need:** `numpy`, `matplotlib`.

На сетке комплексных чисел векторно (цикл только по итерациям, не по точкам)
посчитайте число итераций до расходимости для `z_{n+1} = z_n² + c`, `z_0 = 0`.
Визуализируйте результат через `imshow`.

**Пример:** для сетки `Re ∈ [-2, 1]`, `Im ∈ [-1.5, 1.5]` получается узнаваемый
фрактал; массив итераций имеет форму `(H, W)`, нет цикла `for` по отдельным точкам.

### H4. Параметрические и полярные кривые

**need:** `numpy`, `matplotlib`.

Постройте на одной фигуре (1×3): фигуру Лиссажу `x=sin(3t), y=sin(4t)` в
декартовых координатах (раскрасить по параметру `t` через `scatter`), спираль
Архимеда `r = a + bθ` и кардиоиду `r = 1 + cos θ` — обе в полярных координатах
(`projection='polar'`).

**Пример:** кардиоида на `θ ∈ [0, 2π]` — замкнутая кривая; спираль раскручивается
на нескольких оборотах; Лиссажу окрашена градиентом по `t`.

### H5. Стандартизация матрицы (z-score)

**need:** `numpy`.

Для случайной матрицы `X` формы `(1000, 4)` выполните постолбцовую
стандартизацию **без циклов**: из каждого столбца вычтите его среднее и разделите
на стандартное отклонение (broadcasting по `axis=0`). Проверьте результат.

**Пример:** после стандартизации `X.mean(axis=0)` ≈ `[0 0 0 0]` и
`X.std(axis=0)` ≈ `[1 1 1 1]` (с точностью до численной погрешности).

# Семинар 1. Jupyter Notebook. Практика по визуализации

## Цель

Освоить работу в среде Google Colab / Jupyter Notebook, научиться использовать библиотеки NumPy и Matplotlib для численных вычислений и визуализации математических объектов: функций одной и двух переменных, параметрических кривых, распределений. Все задания выполняются в ноутбуке (`.ipynb`); итоговый файл с кодом, графиками и пояснениями является основным артефактом семинара.

## Теоретический минимум

- **Jupyter Notebook / Google Colab:** интерактивная среда с ячейками кода и текста (Markdown), порядок выполнения ячеек, ядро (kernel) и его перезапуск, горячие клавиши (Shift+Enter, Tab).
- **NumPy ndarray:** основная структура данных для числовых массивов; атрибуты `shape`, `dtype`; создание через `np.array`, `np.zeros`, `np.ones`, `np.linspace`, `np.arange`.
- **Векторизованные операции:** поэлементная арифметика над массивами без явных циклов; broadcasting (сложение массива и скаляра, массива и вектора).
- **Математические функции NumPy:** `np.sin`, `np.cos`, `np.exp`, `np.log`, `np.sqrt` — применяются поэлементно к массивам.
- **Matplotlib pyplot:** фигура (`figure`) и оси (`axes`); базовые команды `plt.plot`, `plt.scatter`, `plt.show`; разница между `plt.plot(x, y)` и объектно-ориентированным интерфейсом (`fig, ax = plt.subplots()`).
- **Подписи и оформление графиков:** `xlabel`, `ylabel`, `title`, `legend`, `grid` — каждый график должен быть подписан, чтобы быть читаемым.
- **Subplots:** `plt.subplots(nrows, ncols)` для размещения нескольких графиков на одной фигуре; `fig.tight_layout()` для корректных отступов.
- **Визуализация 2D-данных:** `np.meshgrid` для построения сетки, `plt.contour` / `plt.contourf` для линий уровня, `plt.imshow` для растровых карт, `plt.colorbar` для шкалы значений.

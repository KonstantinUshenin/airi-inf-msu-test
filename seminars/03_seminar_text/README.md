# Семинар 3. Unix-terminal. Работа с текстами

## Цель

Освоить основные инструменты обработки текста в Unix-терминале: редактировать файлы в nano, vim и ed, просматривать и анализировать содержимое (head, tail, wc), искать текст (grep) и файлы (find), сортировать и дедуплицировать данные (sort, uniq), сравнивать файлы (diff, vimdiff), обрабатывать CSV-данные (xsv). Познакомиться с современными Rust-аналогами классических утилит (uutils coreutils, ripgrep, xsv). Результаты фиксировать в отчёте, артефакты сохранять на диске.

## Теоретический минимум

- **Потоки ввода-вывода:** stdin (0), stdout (1), stderr (2); перенаправление (`>`, `>>`, `2>`) и конвейеры (`|`) как основа обработки текста.
- **Текстовые редакторы:** nano — модeless-редактор с подсказками; vim — модальный редактор (Normal, Insert, Visual, Command-line); ed — строковый редактор, работающий без экрана (полезен для скриптов и удалённой работы по медленным каналам).
- **Регулярные выражения (BRE/ERE):** базовый синтаксис (`.*`, `[]`, `^`, `$`, `+`, `?`, `{}`); разница между BRE (grep) и ERE (grep -E / egrep).
- **Кодировки:** UTF-8 как стандарт; `file`, `iconv` для определения и преобразования кодировок; влияние локали (`LC_ALL`, `LANG`) на сортировку и grep.
- **CSV-формат:** значения через запятую/точку с запятой, экранирование кавычками; почему `cut` и `awk` ломаются на кавычках внутри полей, а специализированные инструменты (xsv) — нет.
- **GNU coreutils:** набор базовых утилит (cat, head, tail, sort, uniq, wc, cut, tr, …); uutils coreutils — кроссплатформенная реализация на Rust.
- **Утилита find:** обход дерева каталогов с фильтрацией по имени, типу, размеру, времени; действия `-exec` и `-print`.
- **diff и patch:** unified diff (`diff -u`), применение патча (`patch`); vimdiff для визуального построчного сравнения.

# Практическая работа

**Выход:** `.py` или `.ipynb`.

Перед началом запустите `./generate.sh`. Все входные файлы для задач появятся в каталогах `assets/B*`, `assets/M*` и `assets/H*`; создавать их вручную не нужно.

## База — 5 задач

### B1. Создание массива

**need:** NumPy.

Создайте массив `float32` формы `(4, 6)` из чисел от 0 до 23. Сохраните `shape`, `ndim`, `dtype`, `size` и `nbytes` в `array-info.json`.

Пример структуры `array-info.json`:

```json
{
  "shape": [4, 6],
  "ndim": 2,
  "dtype": "float32",
  "size": 24,
  "nbytes": 96
}
```

### B2. Индексы и срезы

**need:** `assets/B2/matrix.npy` формы `(6, 8)`.

Сохраните в `slices.npz` вторую строку, третий столбец, блок со строками индексов 2–4 и столбцами индексов 3–6, а также все строки в обратном порядке.

### B3. Статистика измерений

**need:** `assets/B3/measurements.npy` — числовой массив формы `(20, 5)` без `NaN`.

Сохраните в `statistics.npz` среднее, стандартное отклонение, минимум, максимум и медиану каждого столбца, а также индекс максимального значения в каждой строке.

### B4. Повторяемая случайная выборка

**need:** NumPy.

Используя `np.random.normal(size=100)`, получите два одинаковых массива и один отличающийся. Сохраните первый массив в `sample.npy`, а результаты двух сравнений — в `determinism.json`.

Пример `determinism.json`:

```json
{
  "same_seed_equal": true,
  "different_seed_equal": false
}
```

### B5. Из двух форм в одну

**need:** NumPy.

После установки seed `42` создайте случайные массивы форм `(10, 2)` и `(8, 4)`. Сохраните исходные массивы и один массив формы `(13, 4)`, содержащий сначала все элементы первого массива, затем все элементы второго, в `reshape-result.npz`.

## Среднее — 5 задач

### M1. Нормализация показаний

**need:** `assets/M1/sensors.npy` формы `(30, 4)`; каждый столбец имеет ненулевое стандартное отклонение.

Выполните z-нормализацию каждого столбца. Сохраните исходные данные, средние, стандартные отклонения, нормализованные данные и координаты значений, у которых модуль нормализованного значения больше 2, в `normalized.npz`.

### M2. Сводка по станциям

**need:** `assets/M2/temperatures.npy` формы `(14, 6)`: строки — дни, столбцы — метеостанции.

Сохраните в `temperature-summary.npz` среднее, стандартное отклонение, минимум и максимум каждой станции. В `hottest.json` сохраните номер дня, номер станции и значение самого жаркого измерения во всём массиве.

Пример структуры `hottest.json` — значения зависят от входного массива:

```json
{
  "day": 9,
  "station": 4,
  "temperature": 25.7
}
```

### M3. Матричная калибровка

**need:** `assets/M3/raw.npy` формы `(20, 3)` и `assets/M3/calibration.npy` формы `(3, 3)`.

Получите откалиброванные данные матричным умножением. Сохраните в `calibrated.npz` результат, среднее и стандартное отклонение его столбцов, а также индекс столбца с максимальным значением для каждой строки.

### M4. Объединение партий

**need:** `assets/M4/part1.npy`, `assets/M4/part2.npy`, `assets/M4/part3.npy` с четырьмя столбцами и ненулевым стандартным отклонением каждого столбца после объединения.

Объедините партии по строкам и выполните z-нормализацию общего массива. Сохраните исходные партии, объединённый массив, средние, стандартные отклонения и нормализованный массив в `combined.npz`.

### M5. NumPy-файлы внутри TAR

**need:** `assets/M5/dataset.tar.gz` с файлами `dataset/features.npy`, `dataset/labels.npy`, `dataset/metadata.json`; метки равны 0 или 1.

`dataset/metadata.json` имеет вид:

```json
{
  "columns": ["x", "y", "z", "signal"],
  "source": "учебный стенд"
}
```

Прочитайте файлы непосредственно из архива без распаковки всего каталога. Сохраните в `class-statistics.npz` средние и стандартные отклонения признаков отдельно для классов 0 и 1. В `archive-info.json` сохраните форму и тип признаков, число объектов каждого класса и метаданные из архива.

Пример структуры `archive-info.json`:

```json
{
  "shape": [24, 4],
  "dtype": "float32",
  "class0_count": 12,
  "class1_count": 12,
  "metadata": {
    "columns": ["x", "y", "z", "signal"],
    "source": "учебный стенд"
  }
}
```

## Сложное — 5 задач

### H1. Один JSON внутри TAR

**need:** `assets/H1/temperatures.tar.gz` с файлом `weather/temperatures.json`, содержащим список дневных температур.

Пример `weather/temperatures.json`:

```json
[12.4, 13.1, 11.8, 15.0]
```

Прочитайте JSON непосредственно из архива и преобразуйте значения в массив `float64`. Сохраните массив в `temperatures.npy`, а количество дней, среднее, стандартное отклонение, медиану, минимум, максимум и индекс самого жаркого дня — в `temperature-report.json`.

Пример структуры `temperature-report.json` — значения приведены для примера выше:

```json
{
  "days": 4,
  "mean": 13.075,
  "std": 1.2029,
  "median": 12.75,
  "minimum": 11.8,
  "maximum": 15.0,
  "hottest_day": 3
}
```

### H2. Таблица наблюдений из JSON

**need:** `assets/H2/weather.tar.gz` с файлом `weather/records.json`; каждая запись содержит `date`, `temperature`, `humidity`, `wind`.

Пример `weather/records.json`:

```json
[
  {"date": "2026-05-01", "temperature": 14.2, "humidity": 58, "wind": 3.1},
  {"date": "2026-05-02", "temperature": 16.7, "humidity": 63, "wind": 2.4}
]
```

Преобразуйте три числовых поля в матрицу с указанным порядком столбцов. Сохраните матрицу, средние и стандартные отклонения столбцов в `weather.npz`. В `selected.json` сохраните выбранные наблюдения с датой и тремя числовыми полями, где температура выше общей средней температуры, а влажность ниже 60.

Пример структуры `selected.json`:

```json
[
  {"date": "2026-05-08", "temperature": 20.4, "humidity": 54.0, "wind": 4.2}
]
```

### H3. Несколько JSON-партий

**need:** `assets/H3/batches.tar.gz` с файлами `batches/part1.json`, `batches/part2.json`, `batches/part3.json`; каждый файл содержит двумерный числовой массив с четырьмя столбцами.

Пример одной партии:

```json
[
  [1.2, 10.0, 101.4, 1000.0],
  [0.8, 11.5, 98.7, 1012.0]
]
```

Проверьте число измерений и количество столбцов каждой партии, затем объедините их по строкам и выполните z-нормализацию. Сохраните партии, объединённые данные, средние, стандартные отклонения и нормализованные данные в `batches.npz`, а формы исходных партий — в `batch-report.json`.

Пример структуры `batch-report.json`:

```json
{
  "shapes": {
    "batches/part1.json": [6, 4],
    "batches/part2.json": [8, 4],
    "batches/part3.json": [5, 4]
  }
}
```

### H4. Несколько станций

**need:** `assets/H4/stations.tar.gz` с файлом `stations/records.json`; каждая станция содержит `id` и двумерный список `measurements` с колонками температуры, влажности и давления.

Пример `stations/records.json`:

```json
[
  {
    "id": "north",
    "measurements": [
      [17.4, 61.0, 1007.2],
      [18.1, 58.0, 1008.5]
    ]
  }
]
```

Объедините измерения всех станций в одну матрицу и создайте параллельный массив идентификаторов станций. Вычислите средние и стандартные отклонения трёх показателей по всему набору и отдельно для каждой станции. Сохраните матрицу и идентификаторы в `stations.npz`, статистику — в `station-report.json`.

Пример структуры `station-report.json`:

```json
{
  "columns": ["temperature", "humidity", "pressure"],
  "global_mean": [18.2, 57.4, 1008.1],
  "global_std": [2.1, 8.3, 6.7],
  "stations": {
    "north": {
      "count": 7,
      "mean": [17.8, 60.1, 1007.6],
      "std": [1.9, 7.2, 6.1]
    }
  }
}
```

### H5. Конвейер по manifest

**need:** `assets/H5/experiment.tar.gz` с `experiment/manifest.json` и перечисленными в нём JSON-партиями; строки содержат четыре числовых значения или `null`, полностью пустых столбцов нет.

Пример `experiment/manifest.json`:

```json
{
  "columns": ["temperature", "humidity", "pressure", "signal"],
  "files": [
    "experiment/batch1.json",
    "experiment/batch2.json",
    "experiment/batch3.json"
  ]
}
```

Пример одной партии:

```json
[
  [1.0, 10.0, null, 100.0],
  [2.0, 11.0, 51.0, 105.0]
]
```

Прочитайте только файлы, перечисленные в manifest. Проверьте число столбцов, объедините партии, преобразуйте `null` в `NaN`, заполните пропуски средними соответствующих столбцов и выполните z-нормализацию. Сохраните заполненные данные, нормализованные данные, средние и стандартные отклонения в `experiment.npz`. В `experiment-report.json` сохраните имена обработанных файлов, исходные формы партий, число заполненных значений и координаты максимального по модулю нормализованного значения.

Пример структуры `experiment-report.json`:

```json
{
  "files": ["experiment/batch1.json", "experiment/batch2.json", "experiment/batch3.json"],
  "columns": ["temperature", "humidity", "pressure", "signal"],
  "shapes": {
    "experiment/batch1.json": [3, 4],
    "experiment/batch2.json": [2, 4],
    "experiment/batch3.json": [3, 4]
  },
  "filled_values": 4,
  "max_abs_coordinate": [0, 2],
  "max_abs_value": -1.73
}
```
